# Technical Support

## Common Issues and Fixes

### App Not Loading / Blank Screen
Clear your browser cache and cookies, then reload. If the issue persists, try an incognito window or a different browser. This usually resolves stale asset caching issues.

### Slow Performance
Performance issues are often caused by large datasets or too many concurrent browser tabs. Try closing unused tabs, or contact support if the issue continues across sessions.

### Login Failures
Ensure caps lock is off and the correct email is used. If a customer has enabled Two-Factor Authentication (2FA) and lost access to their authenticator app, they must submit a support ticket with identity verification to reset 2FA.

### API Errors (4xx / 5xx)
- 401 Unauthorized: API key is invalid or expired — regenerate it from Account Settings > API Keys.
- 429 Too Many Requests: The account has exceeded its rate limit; upgrading the plan increases the limit.
- 500 Internal Server Error: This is on our end — check our status page, and if it persists more than 15 minutes, escalate to engineering.

### Data Sync Issues
If data isn't syncing across devices, ensure the customer is logged into the same account on all devices and has a stable internet connection. A manual "Force Sync" option is available in Settings > Data > Sync.

## Escalation Guidelines
Technical issues involving data loss, security concerns, or repeated unresolved bugs after 2 support attempts should be escalated to a human engineer rather than resolved automatically.
