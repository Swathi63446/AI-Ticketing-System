# Account Security

## Password Resets
Customers can reset their password via the "Forgot Password" link on the login page. A reset link is emailed and expires after 30 minutes for security reasons.

## Two-Factor Authentication (2FA)
We strongly recommend enabling 2FA via an authenticator app (Google Authenticator, Authy) or SMS. 2FA can be enabled or disabled from Account Settings > Security.

## Suspicious Login Activity
If a customer reports a login from an unrecognized device or location, their account should be temporarily locked and the customer must verify their identity via email confirmation before regaining access. This type of issue is always treated as sensitive and should involve a human review.

## Account Takeover / Compromised Accounts
Any report of unauthorized access, unknown password changes, or unauthorized purchases must be escalated immediately to the security team. Do not attempt to resolve these automatically — always flag for human review given the sensitivity and potential fraud risk.

## Data Privacy Requests
Customers requesting account data export or full account deletion (under GDPR/CCPA-style rights) must be verified and routed to the privacy team; these are not handled by automated responses.

## Security Best Practices Shared with Customers
- Use a unique, strong password (12+ characters)
- Enable 2FA
- Never share account credentials via email or chat
- Review active sessions periodically under Account Settings > Security > Active Sessions
